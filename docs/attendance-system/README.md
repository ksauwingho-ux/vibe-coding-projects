## 三条不可动摇的技术铁律

1. **判定引擎是纯函数** —— 零 DB 依赖，否则 31,792 行回归跑不动
2. **`class_daily_stat` 总和恒等于 `attendance` 实际内容** —— 五条改判路径只许走唯一入口 `apply_judgment_change()`
3. **`lock_judgment` 人工结论锁** —— 请假撤销的"完整重判"必须跳过已锁定行，否则副班长核对的 2,001 条会被静默冲掉

## 三条 CI 门禁

1. 真实数据判定回归（31,792 行 → `正常 15,442 / 旷课 14,185 / 待处理 2,001 / 迟到 164`）
2. 统计一致性断言（随机改判后总和与分组恒等）
3. 页面冒烟 + 越权（24 页面 × 4 角色）
