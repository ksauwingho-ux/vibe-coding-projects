# 接口与字段约定

本文件与 docs/contracts/ 是应用内部前后端契约建议，不是 WPS 官方端点，也不是学校考勤 API 的已验证协议。未指定 URL、鉴权 scope、真实字段 ID、批量上限。Comate 核实实际部署后映射；未知项保留待定。

## 1 连接方式

页面组件 → 应用数据访问层 → 受控业务服务 → WPS 平台适配器/多维表格。
学校 Excel → 导入适配器 → 校验/身份映射/去重 → 原始版本 → 规则 → 业务事实。
后续学校考勤 API → 新采集适配器 → 上述同一链路。

页面不持有平台应用密钥、不直接调用供应商管理接口、不用本地 mock 计算覆盖服务端最终结果。原生表单/审批入口从服务端获取经权限验证的入口信息，不自行拼接带身份或密钥的 URL。

## 2 方法清单：都是待实现的内部方法

| 方法 | 输入 | 输出 | 关键约束 |
|---|---|---|---|
| resolveSession | 由服务端验证的登录态 | 用户、角色范围、映射状态、可用入口 | 角色不取自请求 body |
| listAttendance | 业务日期区间、学期、请求范围、类别、搜索、cursor、limit | items、next_cursor、has_more、total、watermark | 范围由后端相交校验；不能先拉全表再过滤 |
| getAttendanceDetail | attendance_id | 原始/基础/最终结果、原因、版本、流程、allowed_actions | 对记录和附件分别授权 |
| getSummary | 与列表一致的日期及范围 | 六类节次、覆盖、更新时间、水位、指标定义 | 汇总不是当前页合计；未齐不声称完整到课率 |
| listWorkItems | 类别、状态、范围、分页 | 待核对/审核/跟进/同步任务 | 任务状态不替代考勤结果 |
| submitReview | 考勤 ID、动作、理由、证据引用、expected_revision、idempotency_key | 受理 ID、处理状态、新版本或冲突 | 服务端重验授权、防自审、锁定；不接受前端最终结果 |
| saveFollowUp | 工作项 ID、跟进备注、预期版本、幂等键 | in_progress 及新版本 | 不改判、不关闭待办 |
| getApplicationEntry | leave/appeal、关联业务 ID | 原生入口或可用性说明 | 真实实例与身份绑定，不能假造“审批通过” |
| getApplicationState | 请求 ID | 审批阶段、权威结果、apply_status、更新时间 | 批准与考勤已同步分开 |
| startImport / getImport | 文件引用、学期/批次 ID | 预览、校验、分项计数、检查点、覆盖 | 文件发送方式依真实平台验证，不在此虚构 |
| requestExport / getExport | 过滤条件、字段、明细或汇总类型 | 任务状态、授权下载引用/失效时间 | 同一权限和过滤范围；大数据异步任务 |

源平台 Table/Approval/Identity/Message 等适配器沿用 baseline/04；这里的应用 facade 不是第二套平台集成标准。需要实现这些方法，不应把本清单标成已有模块。

## 3 原型字段迁移

| 原型字段 | 正式字段 | 要求 |
|---|---|---|
| id | attendance_id | 不可变文本业务 ID；不能使用数组下标、行号或姓名 |
| studentNo | student_no_snapshot，另保留 student_id | 学号始终文本；保留前导零 |
| name / className | name_snapshot / class_name_snapshot / class_id | 历史快照，转班后不改历史归属 |
| course / date | course_name / att_date / period / session_id | 一人一课一日一节；不能由 checkIn 反推节次 |
| status | raw_result、base_judgment、final_judgment | 原型“未到”无安全的一对一转换 |
| checkIn | sign_time + 原始签到字段 | null 表示缺失，不用展示字符串冒充时间 |
| resolved | work_item.status + 流程状态 | 不直接映射 final_judgment |
| result / note | review_event 或跟进记录 | 带操作者、时间、版本和来源；不覆盖原始行 |
| 固定 09:42 | updated_at / source_watermark | 后端返回，显示北京时间 |
| 林老师 | session.display_name | 展示名不是权限依据 |

六类 final_judgment 沿用基线中文枚举：正常、旷课、迟到、早退、请假、待处理。UI 将“待处理”显示为“待核实”时只改变标签，不改变数据值。正式 API 若用英文状态码，在唯一映射层转换，未知值不默认正常。

所有 ID 和学号为文本；日期为 YYYY-MM-DD；时间为含时区的 ISO 8601 或经确认的 UTC 时间戳，业务展示/定时统一 Asia/Shanghai。无值用 null，不能把 0、空数组、无数据和加载失败混成同一状态。

## 4 分页、统计与竞态

- 服务端适配真实 cursor 或页码。底层为 cursor 时，前端只维护已获得的游标链；没有能力时不提供虚假的任意跳页。
- total 无法可靠取得时可为 null，UI 展示“已加载”，不伪造总页数。
- 过滤条件变化重置分页；取消旧请求或以 request sequence 丢弃过期响应，避免旧列表覆盖新筛选。
- 明细、汇总、导出带一致 query 范围与 source_watermark；未同步则明确提示，不把旧统计当成当前已完成。
- total_imported_periods = 六类数量之和；abnormal_periods = 旷课＋迟到＋早退；pending_verification_periods = 待处理。
- 应到分母、请假是否从分母剔除、迟到/早退折算与人数去重口径待确认；没有确认的完整来源和规则，不返回权威 attendance_rate。示例中 expected_periods 和 attendance_rate 为 null。
- 导出所有授权的筛选结果，不止本页；统计页面明确导出“明细”还是“汇总”。

## 5 写入、错误与安全边界

动作由服务端验证当前账号、有效角色、范围、对象版本、本人排除和锁定。allowed_actions 仅用于界面提示，不能代替提交时校验。

结果成功只在服务端确认受理/生效后展示对应状态。已受理未生效显示“处理中”，同步失败显示“已受理，同步异常”，不先改 UI 假装完成。请求超时保留输入，先按 operation_id/幂等键查状态；同一动作重试使用同一键。

| 内部错误码建议 | 典型 HTTP 映射（待服务端确认） | 页面处理 |
|---|---|---|
| UNAUTHENTICATED | 401 | 提示重新认证，不清空草稿，不把失效当无数据 |
| FORBIDDEN | 403 | 不展示受限内容，不自动扩大范围 |
| NOT_FOUND | 404 | 记录不存在或不可访问，按服务端策略避免泄露 |
| REVISION_CONFLICT | 409 | 保留备注，刷新最新版本后重新决策 |
| VALIDATION_ERROR | 400/422 | 字段旁显示原因，禁止重复盲提交 |
| RATE_LIMITED | 429 | 遵守重试窗口，避免无限轮询 |
| UPSTREAM_UNAVAILABLE | 502/503 | 显示更新时间与重试，不降级到 mock 冒充真实 |
| RESULT_UNKNOWN | 超时或应用状态 | 查操作状态，不能认定失败后再创建一次 |

原生资源、关联字段、附件、下载和深链接均需范围校验。生产数据不缓存到未受控的浏览器持久存储。日志不记录凭证、完整附件或病历。CSV 应防公式执行并保留学号文本；不能只依赖 CSV 双引号转义公式。
