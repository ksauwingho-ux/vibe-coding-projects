# 从无到有 · GENESIS（30 秒生成式短片）

纯代码生成：画面由 Canvas 逐帧渲染，配乐由 Python 合成，无任何素材和采样。成片见 `genesis.mp4`（1920×1080 / 30fps / 约 36MB）。

| 时间 | 内容 |
| --- | --- |
| 0–8.5s | 一个光点 + 心跳逐渐加速，17000 颗尘埃被引力卷入 |
| 8.7–9.0s | 塌缩成一个点，彻底静音 |
| 9.0s | 大爆炸：白闪、冲击波、1.6 万颗粒子、次声重击 |
| 11–19s | 星系在余烬中成形（4 万颗恒星），138 亿年前 |
| 19–24.6s | 镜头加速拉远，穿过 3.4 万个星系组成的宇宙网，约 2000 亿个星系 |
| 24.6–27.6s | 一切安静，只剩一个点：你在这里 |
| 28s | 标题「从无到有」 |

重新生成：`./build.sh`（依赖 node + playwright/chromium、python3 + numpy + scipy、ffmpeg、字体 Noto Sans CJK）。
`film.html` 里的 `renderFrame(t)` 是纯函数，同一个 t 永远画出同一帧，所以可以并行渲染。
